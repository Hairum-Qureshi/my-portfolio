# Personal Portfolio

My personal developer portfolio, built with React and Tailwind CSS.

The site serves as a central place to showcase my projects, technical skills, experience, and background as I continue growing as a software engineer.

## Tech Stack

* **React** — Frontend UI
* **TypeScript** — Type-safe JavaScript
* **Tailwind CSS** — Styling and responsive design

## Features

* Personal introduction and background
* Projects and development work
* Technical skills
* Education and experience
* Responsive design for desktop and mobile
* Clean, minimal interface focused on content and readability

## Purpose

This portfolio is primarily a showcase of my development work and a place to document my growth as a software engineer.

Rather than trying to demonstrate every technology I know, the goal is to highlight projects that reflect how I approach software development and the technologies I am currently learning and working with.
